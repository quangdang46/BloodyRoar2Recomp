## About This Project

This project is an independent reverse-engineering, preservation, and
enhancement initiative.

The project aims to:

- Reimplement and preserve the original gameplay experience.
- Develop modern cross-platform support (Windows, macOS, Linux, Web).
- Introduce AI agent gameplay: agent versus agent, human versus agent, and
  agent versus CPU.
- Provide modern rendering, controls, and accessibility improvements.
