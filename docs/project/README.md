# docs/project — canonical objective docs

Per the project vision (see GOALS.md), agents must read these before
work. `AGENTS.md` at repo root remains the operational handbook and
takes precedence on workflow/verification/git rules.

- `GOALS.md` — what we're building and the reconstruction standard.
- `ROADMAP.md` — phases, current position, ordering rationale.
- `PROGRESS.md` — live dashboard; update after significant work.
- `SPEC.md` — (planned) technical requirements/architecture detail.
- `ARCHITECTURE.md` — (planned) module map of game/ + runtime.
